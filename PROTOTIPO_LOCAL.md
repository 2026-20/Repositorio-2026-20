# Prototipo local - NO es el incremento real de Sprint 3

Esta rama (`sprint3-prototipo-local`) es temporal y vive solo en esta máquina.
Se construyó para tener datos/pantallas reales que mostrar en pruebas de
usabilidad con usuarios expertos, mientras el Sprint 3 real todavía no
arranca formalmente con el equipo.

**No pushear esta rama. No mergear contra main. No citar los resultados de
la prueba de usabilidad como si fueran sobre el incremento real** -- son
sobre este prototipo, documentarlo así.

Alcance de este prototipo: únicamente lógica de conteo (HU-005, HU-006,
HU-007, HU-008, HU-025, HU-026, HU-027, HU-028, HU-030, HU-032). Comunicación
con el ERP, alertas, reportes y devolución quedan fuera a propósito.
