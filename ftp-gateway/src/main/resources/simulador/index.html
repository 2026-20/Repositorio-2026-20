Simulador de ingesta FTP

Sube un XML como si llegara por el FTP real del ERP — este formulario lo reenvía al backend exactamente por el mismo camino que usa ReenviadorAlBackend cuando el archivo viene del FTP (mismos headers, mismo endpoint por nombre de archivo). Solo para pruebas.



Se precarga con el nombre real del archivo elegido, pero es editable — el endpoint se decide por este nombre (substring), no por el contenido. Para cai_det_mov y cai_lot_mov además tiene que calzar el patrón org_usuario_bodega_fechaCorta_cai_{det|lot}_mov_YYYY-MM-DD_HHmm_secuencia.xml.

Ruteo por nombre de archivo: cai_bod → bodegas · cai_est_vis → estados-visita · cai_det_bod → detalle-bodega · cai_lot_bod → lote-bodega · cai_det_mov → movimientos-pendientes · cai_lot_mov → lotes-movimiento.
